A PostgreSQL client and database studio. The left drawer shows the databases on the server
configured in Settings; tap one to open a full studio as an editor tab with Tables, Query,
Diagram, Security and Backup panes. Browse and edit table data, view table structure, create /
rename / drop tables, run ad-hoc SQL with a results grid, see an auto-generated entity-relationship
diagram of the schema, inspect roles and privileges, and back up / restore databases with pg_dump /
pg_restore. Uses the ARM64-native psql client, installed on first use from the distro's own apt
repo. Connects to any reachable PostgreSQL — a remote host, a cloud instance, or a server on your
network. Connection details (host, port, role, password, database, SSL mode) live in app Settings,
so no credentials are entered in the UI.
